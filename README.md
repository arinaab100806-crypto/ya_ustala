# ВолгаКод

Веб-платформа для алгоритмических задач, турниров, организаций, команд и проверки похожих решений. Участник регистрируется, пишет код в редакторе и получает вердикт Judge0. Организатор проводит индивидуальный или командный турнир и после завершения скачивает отчёт.

## Что нужно установить

- Python 3.9 или новее. На Windows, если `python` не находится, используйте `py -3`.
- Node.js 20 или новее и npm.

Проверка кода идёт через Judge0. Если `JUDGE0_URL` пустой, «Запустить» и «Отправить решение» отвечают, что проверка недоступна, и вердикт не сохраняется.

## Запуск

Откройте два терминала из корня проекта.

### Backend

```powershell
cd backend
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Если `py` нет, первая команда — `python -m venv .venv`. На macOS и Linux активация: `source .venv/bin/activate`.

При первом запуске создаётся `backend/codearena.db` и в неё записываются 9 задач с открытыми примерами и скрытыми тестами. Пароли хранятся как PBKDF2-хеш. API: http://127.0.0.1:8000 , описание маршрутов: http://127.0.0.1:8000/docs .

### Frontend

```powershell
cd frontend
npm install
npm run dev
```

Сайт открывается на http://127.0.0.1:5173 . Запросы к `/api` проксируются на backend, поэтому оба процесса должны работать.

## Роли

- Участник. Обычная регистрация всегда создаёт участника.
- Организация. Отдельная регистрация создаёт владельца и организацию. Владелец добавляет сотрудников-организаторов по имени пользователя.
- Администратор. Появляется из `ADMIN_USERNAME`, `ADMIN_EMAIL` и `ADMIN_PASSWORD` в `backend/.env`, только если администратора ещё нет. Он видит пользователей и организации и назначает роли. Единственного администратора снять нельзя.
- Капитан — это роль внутри команды, а не отдельный тип учётной записи. Участник состоит только в одной команде.

## Как пользоваться

1. Зарегистрируйтесь. На главной после входа видны решённые задачи, турниры и последние отправки. Там же можно указать ФИО и дату рождения: они попадут в отчёт организатора, если вы их сохранили.
2. В каталоге задач есть поиск, сложность и категория. Под названием видны автор и категория. Зелёная точка означает, что у вас уже был OK.
3. На странице задачи слева условие, справа Monaco Editor. Языки: Python, C++, Java и JavaScript. «Запустить» проверяет только примеры и ничего не сохраняет. «Отправить решение» проверяет все тесты и пишет результат в историю. Вердикты: OK, WA, TLE, RE, CE. Вход и ожидаемый ответ показываются только для открытого примера. Скрытый тест в ответе не раскрывается.
4. Производственные задачи организации публикуются в отдельной витрине. Скрытая задача не видна в каталоге, и запустить её может только сотрудник этой организации.
5. Организатор создаёт соревнование: задачи, дата, длительность, индивидуальный или командный формат. Турнир можно связать со своей организацией. В корпоративный турнир производственная задача попадает только из этой организации, и только если она опубликована. Черновик виден автору. После публикации турнир видят все. Пока турнир не начался, регистрацию можно отменить, а условие можно менять. После старта состав и условие фиксируются. Идущий турнир организатор может завершить досрочно.
6. На индивидуальный турнир участник записывается сам. На командный капитан записывает всю текущую команду. Личная запись на командный турнир закрыта. В таблице одна строка на участника или на команду: больше решённых задач — выше, при равенстве выше тот, у кого меньше суммарное время от старта до первого OK по каждой задаче.
7. Команды ищутся по названию, специализации и открытому набору. Капитан принимает заявки и меняет состав. Повторная заявка после отказа не отправляется, в закрытую или полную команду вступить нельзя.
8. «Проверка ответов» на странице турнира сравнивает решения разных участников. Пока анализ не запускали, страница так и сообщает. В отчёт попадают только подозрительные совпадения. Короткие типовые решения и решения участников одной команды в командном турнире не отмечаются. Организатор смотрит оба кода, процент сходства и пояснение и вручную ставит «проверено». Места в таблице от этого не меняются, дисквалификация не выставляется.
9. После завершения турнира организатор или сотрудник его организации формирует PDF, XLSX или CSV. В файле название, даты, формат, места, баллы, время и состав команды. В базе хранится имя файла, сам файл лежит в `backend/data/reports/`. Участник отчёт не скачивает. Такой файл не заменяет документ для присвоения спортивного разряда. Для PDF нужен шрифт с кириллицей: на Windows используется Arial, другой путь задаётся через `REPORT_FONT`.
10. В разделе «Матчи» есть дуэль 1×1 и командный матч 2×2. Соперника или напарников можно найти автоматически или пригласить по ссылке. В дуэли оба видят время и этап: написание кода или правка ответа. Если один участник решает все задачи верно, матч останавливается и на экране появляется его имя и кубок. В командном режиме организатор комнаты задаёт порядок задач и назначает, кто из пары какую задачу решает.

## Judge0

Скопируйте `backend/.env.example` в `backend/.env`.

Свой сервер:

```env
JUDGE0_URL=http://127.0.0.1:2358
```

RapidAPI Judge0 CE:

```env
JUDGE0_URL=https://judge0-ce.p.rapidapi.com
JUDGE0_API_KEY=ваш_ключ
JUDGE0_API_HOST=judge0-ce.p.rapidapi.com
```

Идентификаторы языков по умолчанию соответствуют Judge0 CE: Python 71, C++ 54, Java 62, JavaScript 63. Если у сервера другие id, задайте `JUDGE0_LANG_PYTHON`, `JUDGE0_LANG_CPP`, `JUDGE0_LANG_JAVA`, `JUDGE0_LANG_JAVASCRIPT`.

Перезапустите backend. Предупреждение в шапке сменится на строку про Judge0. Поменяйте `SECRET_KEY`, если сайтом пользуется кто-то кроме вас.

## Проверка

Из папки `backend` с активированным виртуальным окружением:

```powershell
python smoke_test.py
```

Скрипт поднимает временную базу и проверяет регистрацию, роли, каталог, отказ проверки без Judge0, турниры, организации, команды, проверку ответов, отчёты и то, что данные читаются после повторного открытия базы. Таблица результатов проверяется по сохранённым отправкам, без локальной имитации судьи.

## Структура

```text
backend/app/main.py                 точка входа FastAPI
backend/app/models.py               пользователи, задачи, турниры, организации, команды, проверка ответов, отчёты
backend/app/routers/                маршруты API
backend/app/judge.py                проверка через Judge0
backend/app/fairplay.py             сравнение решений
backend/app/contest_reports.py      PDF, XLSX и CSV
backend/app/seed.py                 стартовые задачи
frontend/src/pages/                 страницы интерфейса
frontend/src/components/            шапка, кнопки, бейджи
```
